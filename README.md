# mongsil-bot

이터널 리턴 전적을 조회하는 디스코드 봇 몽실봇입니다.\
닉네임으로 랭크, 전적, 플레이 타임을 디스코드 안에서 확인합니다.

## 기능

- `/랭크`: 티어, RP, 다음 티어까지 남은 RP, 서버 순위나 상위 백분율, 승률, 평균 순위, 킬과 어시스트, 모스트 실험체
- `/랭킹`: 아시아1 서버 상위 100명 랭킹, 버튼으로 페이지 넘김.\
  이 서버 버튼은 `/계정`으로 닉네임을 등록한 서버 멤버끼리의 순위
- `/이터컷`: 이터니티와 데미갓 RP 컷
- `/플탐`: 최근 7일 플레이 타임과 모드별 게임 수
- `/시즌`: 현재 시즌 정보
- `/동접`: 현재 동시 접속자 수, 어제 같은 시각 대비 증감, 최근 7일 차트
- `/계정`: 내 닉네임 등록.\
  등록하면 `/랭크`, `/플탐`, `/랭킹` 내 순위, `/이터컷` 내 RP와 비교에서 닉네임을 입력하지 않아도 되고 `/랭킹` 서버 순위에 들어감
- `/강아지`, `/고양이`: 무작위 동물 사진
- `/설정`: 이모지 확대 켜고 끄기, 패치 노트, 점검, 매일 이터컷 알림을 받을 채널 정하기, 대시보드 링크.\
  서버 관리 권한이 있어야 보임
- `/정보`: 서버 수와 30일 참가, 퇴장, 닉네임 등록 수, 업타임, 핑, 오늘 명령어, 이 서버의 사용량과 이모지 확대 상태, 지원 서버, 초대, 대시보드, Labs 링크
- 커스텀 이모지 하나만 보낸 메시지를 웹후크로 확대해 다시 보냄
- 웹 대시보드: 첫 화면은 명령어별 실제 출력을 30분마다 실데이터로 다시 그려 보여 줌.\
  디스코드 계정으로 로그인하면 관리 권한이 있는 서버의 설정을 바꾸고 최근 30일 명령어 사용량을 볼 수 있음.\
  설정은 이모지 확대와 명령어를 쓸 채널, 오래된 초대 링크 정리, 알림 채널이고 바꾼 내역이 변경 기록에 남음.\
  봇 소유자는 30일 사용량, 명령어별 실행과 오류율, 응답 시간, 많이 쓰는 서버, 서버 참가와 퇴장을 운영 현황 화면에서 볼 수 있음

## 동작 방식

bser Open API로 전적을, Steam Web API로 동시 접속자 수를 가져옵니다.\
대시보드는 봇과 같은 프로세스에서 실행되며, 로그인은 Discord OAuth2의 `identify`, `guilds` 범위만 씁니다.

## 실행

```bash
pip install -r requirements.txt

# .env 작성
printf 'BOT_TOKEN=...\nAPI_KEY=...\n' > .env

# 첫 실행은 슬래시 명령 동기화를 켜고 실행
SYNC_COMMANDS=1 python main.py

# 이후 실행
python main.py
```

## 설정

| 키 | 설명 |
|---|---|
| BOT_TOKEN | 디스코드 봇 토큰.<br>필수 |
| API_KEY | bser Open API 키.<br>필수 |
| STEAM_API_KEY | Steam Web API 키.<br>없으면 `/동접`이 동작하지 않음 |
| SENTRY_DSN | Sentry DSN.<br>비워 두면 어디로도 보내지 않음 |
| SYNC_COMMANDS | `1`이면 시작할 때 슬래시 명령을 동기화 |
| DASHBOARD_URL | 대시보드 공개 주소.<br>예: `https://bot.example.com`.<br>개발자 포털 OAuth2 Redirects에 `<주소>/auth/callback`을 등록해야 함 |
| DASHBOARD_CLIENT_SECRET | 개발자 포털 OAuth2의 Client Secret.<br>이 값과 DASHBOARD_URL이 둘 다 있어야 대시보드가 켜짐 |
| DASHBOARD_PORT | 대시보드 포트.<br>기본 8095 |
| DASHBOARD_HOST | 대시보드가 받을 주소.<br>기본 0.0.0.0 |
| LOG_FILE | 로그를 파일에도 남길 경로.<br>비워 두면 표준 출력만 |
