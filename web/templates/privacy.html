개인정보 처리방침

2026년 10월 16일부터 적용

몽실봇 디스코드 봇과 대시보드 bot.mongsil.dev가 어떤 정보를 왜 저장하고 언제 지우는지 적은 문서입니다. 몽실봇은 개인이 운영하는 무료 서비스입니다.

저장하는 정보

정보저장하는 때쓰는 곳보관 기간
디스코드 유저 ID, 서버 ID, 명령어 이름, 처리 결과와 걸린 시간명령어를 쓸 때사용량 통계, 오류 확인1년
디스코드 유저 ID, 서버 ID이모지 확대가 동작할 때사용량 통계1년
디스코드 유저 ID, 이터널 리턴 닉네임과 계정 번호/계정으로 닉네임을 등록할 때닉네임 없이 전적 조회, 서버 순위등록 해제할 때까지
디스코드 유저 ID, 사용자 이름, 프로필 사진 주소, 디스코드 로그인 토큰대시보드에 로그인할 때로그인 유지, 관리할 수 있는 서버 확인로그아웃하거나 로그인 7일 뒤까지
디스코드 유저 ID, 사용자 이름서버 설정을 바꿀 때서버의 설정 변경 기록1년
서버 ID, 서버 이름, 멤버 수몽실봇이 서버에 들어가거나 나올 때운영 통계1년

이모지 확대는 커스텀 이모지만 보낸 메시지를 찾으려고 채널 메시지를 읽지만, 메시지 내용은 저장하지 않습니다. 보관 기간이 지난 기록은 매일 자동으로 지웁니다.

외부 서비스

  • Discord, 미국: 봇과 대시보드 로그인이 Discord 위에서 동작합니다.
  • 이터널 리턴 Open API, 대한민국: 전적을 조회할 때 닉네임과 계정 번호를 보냅니다.
  • Cloudflare, 미국: 대시보드 접속이 Cloudflare를 거치며 접속 IP 주소가 처리됩니다.
  • Sentry, 미국: 오류가 나면 오류 내용이 전송됩니다. 오류가 난 명령의 서버 ID, 유저 ID, 닉네임이 함께 들어갈 수 있고 Sentry의 보관 기간에 따라 지워집니다.

그 밖의 곳에 정보를 팔거나 넘기지 않습니다.

지우기와 열람 요청

  • /계정의 등록 해제 버튼으로 닉네임 등록 정보를 바로 지울 수 있습니다.
  • 대시보드에서 로그아웃하면 로그인 정보가 지워집니다.
  • 그 밖의 기록을 보거나 지우거나 처리를 멈추고 싶으면 지원 서버나 이메일로 요청해주세요. 본인 확인 뒤 처리합니다.

안전 조치

기록은 운영자만 접근할 수 있는 서버에 저장합니다. 디스코드 로그인 토큰은 서버에만 두고 브라우저에는 무작위 세션 값만 보냅니다. 대시보드는 HTTPS로만 접속됩니다.
