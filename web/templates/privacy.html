개인정보 처리방침

2026년 10월 16일 시행

  • 대상: 몽실봇 디스코드 봇과 대시보드 bot.mongsil.dev
  • 개인이 운영하는 무료 서비스

1. 처리 목적

  • 명령어 응답과 서버 설정 적용
  • /계정에 등록한 닉네임으로 전적 조회
  • 대시보드 로그인과 관리 권한 확인
  • 사용량 통계와 오류 확인

2. 처리 항목과 보유 기간

항목수집 시점목적보유 기간
디스코드 유저 ID, 서버 ID, 명령어 이름, 처리 결과와 걸린 시간명령어 사용사용량 통계, 오류 확인1년
디스코드 유저 ID, 서버 ID이모지 확대사용량 통계1년

  • 이모지 확대는 커스텀 이모지만 보낸 메시지를 찾으려고 채널 메시지를 읽음, 메시지 내용은 저장하지 않음

3. 파기 절차와 방법

  • 보유 기간이 지난 기록은 매일 자동으로 데이터베이스에서 삭제, 복구할 수 없음
  • 암호화한 백업본은 최대 5주 뒤 삭제
  • 법령에 따라 따로 보존하는 정보 없음

4. 제3자 제공

  • 이터널 리턴 Open API, 님블뉴런, 대한민국: 전적 조회 때 닉네임과 계정 번호 전송, 조회 목적에만 사용
  • 그 밖의 제3자 제공과 판매 없음

5. 처리 위탁과 국외 이전

받는 곳국가업무와 항목시기와 방법보유 기간
Sentry, Functional Software, Inc., compliance@sentry.io미국오류 기록. 오류가 난 명령의 서버 ID, 유저 ID, 닉네임이 들어갈 수 있음오류가 날 때 네트워크로 전송Sentry 보관 정책에 따름
Cloudflare, Inc., dpo@cloudflare.com미국대시보드 접속 중계와 백업 보관. 접속 IP 주소, 요청 정보, 암호화한 백업본접속할 때와 매일 백업 때 네트워크로 전송접속 기록은 Cloudflare 정책, 백업본은 최대 5주
  • 근거: 서비스 제공에 필요한 처리위탁과 보관, 개인정보 보호법 제28조의8 제1항 제3호
  • 거부 방법: 봇 명령어와 대시보드를 쓰지 않으면 이전되지 않음, 거부하면 해당 기능 이용 불가

6. 정보주체의 권리와 행사 방법

  • 개인정보 열람, 정정, 삭제, 처리 정지 요구 가능
  • 닉네임 등록 정보는 /계정의 등록 해제 버튼으로, 로그인 정보는 대시보드 로그아웃으로 바로 삭제
  • 그 밖의 요구는 지원 서버나 이메일로 접수, 본인 확인 뒤 지체 없이 처리
  • 만 14세 미만 아동은 법정대리인이 요구 가능, 대리인 요구 시 위임 사실 확인

7. 쿠키

  • mb_session: 대시보드 로그인 유지, 최대 7일
  • mb_state: 디스코드 로그인 중 위조 요청 방지, 10분
  • 광고나 방문 분석 쿠키 없음
  • 브라우저에서 쿠키를 막으면 대시보드 로그인 불가

8. 안전성 확보 조치

  • 기록은 운영자만 접근할 수 있는 서버에 저장
  • 디스코드 로그인 토큰은 서버에만 두고 브라우저에는 무작위 세션 값만 전달
  • 대시보드는 HTTPS 접속만 허용, 백업본은 암호화해 보관

9. 개인정보 보호책임자
