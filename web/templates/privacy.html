개인정보 처리방침

2026년 10월 20일 시행

몽실봇 디스코드 봇과 대시보드 bot.mongsil.dev가 처리하는 개인정보를 개인정보 보호법 제30조에 따라 공개합니다.
몽실봇은 개인이 운영하는 무료 서비스입니다.

1. 처리 목적

  • 명령어 응답, 서버 설정 적용과 변경 기록
  • /계정에 등록한 닉네임으로 전적 조회와 서버 순위
  • 대시보드 로그인과 관리 권한 확인
  • 사용량과 운영 통계
  • 오류 확인과 남용 방지
  • 방문 통계

2. 처리 항목과 보유 기간

항목수집 시점보유 기간
디스코드 유저 ID, 서버 ID, 명령어 이름, 처리 결과와 걸린 시간명령어를 쓸 때1년
디스코드 유저 ID, 서버 ID이모지 확대가 동작할 때1년
디스코드 유저 ID, 이터널 리턴 닉네임과 계정 번호/계정으로 닉네임을 등록할 때등록 해제까지
디스코드 유저 ID, 사용자 이름, 프로필 사진 주소, 디스코드 로그인 토큰대시보드에 로그인할 때로그아웃 또는 로그인 7일 뒤까지
디스코드 유저 ID, 사용자 이름서버 설정을 바꿀 때1년
서버 ID, 서버 이름, 멤버 수몽실봇이 서버에 들어가거나 나올 때1년
방문한 페이지 주소, 브라우저와 기기 정보, 방문 통계 쿠키 식별자대시보드 페이지를 조작하거나 10초 넘게 볼 때수집일로부터 14개월
서버 접속 기록: 접속 IP 주소, 요청한 주소, 브라우저 정보대시보드에 접속할 때기록이 100MB를 넘으면 오래된 것부터 지움

이모지 확대는 이모지만 보낸 메시지를 찾으려고 채널 메시지를 읽지만, 메시지 내용은 저장하지 않습니다.

3. 파기

보유 기간이 지난 기록은 매일 자동으로 지웁니다.
암호화한 백업본은 최대 5주 뒤 지워집니다.
지운 정보는 되살릴 수 없습니다.

4. 제3자 제공

전적을 조회할 때 닉네임과 계정 번호를 님블뉴런의 이터널 리턴 Open API에 보냅니다.
이 경우를 제외하면 개인정보를 제3자에게 제공하거나 판매하지 않습니다.

5. 처리 위탁과 국외 이전

받는 곳국가업무와 항목
Sentry
compliance@sentry.io		미국오류 기록.
오류가 난 명령어의 서버 ID, 유저 ID, 닉네임이 오류가 날 때 전송됨.
보유 기간은 Sentry 보관 정책을 따름
Cloudflare
dpo@cloudflare.com		미국대시보드 접속 중계, 방문 통계, 백업 보관.
접속 IP 주소, 요청 정보, 방문한 페이지 주소, 브라우저 종류가 접속할 때마다, 암호화한 백업본이 매일 전송됨.
방문 통계는 쿠키를 쓰지 않음.
보유 기간은 Cloudflare 정책을 따르고, 백업본은 최대 5주
Google LLC
googlekrsupport@google.com		미국Google 애널리틱스 방문 통계 분석.
쿠키 식별자, 방문한 페이지 주소, 브라우저와 기기 정보, 접속 IP 주소가 대시보드 페이지를 조작하거나 10초 넘게 볼 때 전송됨.
보유 기간은 수집일로부터 14개월

위 국외 이전은 서비스 제공에 필요한 처리 위탁이며, 개인정보 보호법 제28조의8 제1항 제3호에 따릅니다.
봇과 대시보드를 쓰지 않으면 개인정보가 국외로 이전되지 않으며, 이전을 원하지 않으면 해당 기능을 쓸 수 없습니다.
Google 애널리틱스 수집만 거부하는 방법은 6번 항목에 있습니다.

6. 쿠키

  • __Host-mb_session: 대시보드 로그인 유지, 최대 7일
  • __Host-mb_state: 디스코드 로그인 중 위조 요청 방지, 10분
  • _ga, _ga_S3NS09MHSM: Google 애널리틱스 방문자 구분, 최대 2년

광고 쿠키는 쓰지 않습니다.
쿠키를 막으면 대시보드에 로그인할 수 없습니다.
Google 애널리틱스의 수집만 거부하려면 Google 애널리틱스 차단 브라우저 부가기능을 설치하면 됩니다.

7. 안전 조치

  • 운영자만 접근할 수 있는 서버에 저장
  • 로그인 세션 값은 해시로 저장하고, 디스코드 로그인 토큰은 서버에만 둠
  • HTTPS 접속만 허용, 백업본 암호화

8. 정보주체의 권리

언제든지 자신의 개인정보 열람, 정정, 삭제, 처리 정지를 요구할 수 있습니다.
닉네임 등록 정보는 /계정의 등록 해제 버튼으로, 로그인 정보는 대시보드 로그아웃으로 바로 지워집니다.
그 밖의 요구는 지원 서버나 아래 이메일로 보내 주시면 본인 확인 뒤 바로 처리합니다.
만 14세 미만 아동의 권리는 법정대리인이 행사할 수 있습니다.
